# Apixly Creative Controls privacy notice

Effective October 23, 2026. Contact: support@apixly.ai.

This plugin processes your base prompt and typed creative controls inside the Dify plugin runtime, which may be hosted on your server or by another operator. It requires no Apixly account, API key or password, and makes no request to Apixly or a model provider. It returns composed prompt text and structured output to Dify. It does not add independent telemetry, file writes, credential storage or external network calls.

Dify may retain workflow inputs, outputs and execution records according to the workspace operator's configuration. Review your Dify operator's policy before including sensitive text. You control deletion of Dify workflows and their records through that operator.

If you connect the resulting prompt to Apixly Media or another tool, that later tool's API calls, billing and data processing are controlled by its own credentials, implementation and privacy notice. This free compiler does not submit those later requests itself.
