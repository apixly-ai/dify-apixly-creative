# Presentation assets

The cover is an explicitly illustrative diagram, adapted from the existing official Apixly branding and Dify cover. It is not a screenshot. Camera, Zap and Aperture symbols reuse the Lucide icon family used by Apixly Studio; its license is included.

The desktop and 375px images are unchanged native Dify Community 1.17.1 preview results from an explicit demo with all three control groups enabled. The shared compiler produced the final prompt without an account, Key or generation. Downloadable workflows keep controls off by default. These result screenshots do not claim a custom Dify node shell, Dify Cloud compatibility or current split-node editor qualification.

No customer uploads, credentials, signed content links, private task/request IDs or billing receipts are included. SHA256 values and source descriptions are in `provenance.json`. Files under `docs/**` are repository assets and are excluded from `.difypkg`; README references use public raw GitHub URLs.
